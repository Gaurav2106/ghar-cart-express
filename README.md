# GharMart Express

Build GharMart, a production-ready Indian grocery and daily-essentials quick-commerce platform based on the attached specification. Build the foundational Phase 1 architecture and customer storefront: an original brand identity (warm Indian grocery aesthetic with modern quick-commerce speed), delivery location selector (pincode/address), category navigation, featured daily essentials with unit pricing and discount tags, responsive mobile-first UI with search, cart drawer, and the layout foundation for the customer portal and admin dashboard.
